Spotify Web Player Clone

This project is a front-end clone of the Spotify Web Player interface built using HTML5 and CSS3. It replicates the layout and styling of Spotify’s web application, including navigation, sidebar, content feed, and preview banner.

⸻

Features
	•	Fixed top navigation bar
	•	Sidebar with playlist & library section
	•	Trending Songs section
	•	Top Artists section
	•	Popular Albums & Singles section
	•	Popular Radio section
	•	Footer with company & community links
	•	Fixed bottom preview banner
	•	Scrollable content areas
	•	Hover effects and interactive cursor styling
	•	Clean dark theme design

⸻

Technologies Used
	•	HTML5
	•	CSS3
	•	Bootstrap Icons (CDN)
